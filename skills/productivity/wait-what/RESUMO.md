# Resumo: wait-what

**O que faz:** quando a sua última mensagem não foi compreendida, pede que ela seja refeita. A resposta traz um pouco de contexto, usa ASD-STE100 Simplified Technical English e a linguagem ubíqua definida no `GLOSSARY.md`.

**Quando usar:** logo depois de uma resposta que não fez sentido ou de uma explicação confusa, para receber uma nova versão mais clara.

**Como invocar:** `/wait-what`. É uma skill só para o usuário (`disable-model-invocation: true`), o agente não a chama sozinho.

**Arquivos:** `SKILL.md` (original em inglês), `TRADUCAO.pt-BR.md` (tradução) e este `RESUMO.md`.
