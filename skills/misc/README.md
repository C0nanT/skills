# Misc

Tools I keep around but rarely use, not promoted in the plugin.

- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: Set up Husky pre-commit hooks with lint-staged, Prettier, type checking, and tests.
- **[setup-statusline](./setup-statusline/SKILL.md)**: Install a Claude Code status line showing model, context usage (% + tokens), rate limits, and git branch.
- **[reset-agent-env](./reset-agent-env/SKILL.md)**: Wipe global agent skills, hooks, rules, and MCP configs across Claude Code, Cursor, Windsurf, and Antigravity to simulate a clean machine.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)**: Disciplined diagnosis loop for hard bugs and performance regressions: build a feedback loop that goes red on this bug → minimise → hypothesise → instrument → fix → regression-test.
