# Resumo: grill-with-docs

**O que faz:** faz uma entrevista implacável sobre um plano ou design, como a `grill-me`, mas também vai atualizando os documentos do projeto enquanto as decisões se fecham: termos no `GLOSSARY.md` e decisões de trade-off em ADRs dentro de `docs/adr/`. Esses documentos são os únicos arquivos que ela escreve.

**Quando usar:** quando você está desenhando uma funcionalidade ou arquitetura e quer que o glossário e as decisões registrados acompanhem a conversa.

**Como invocar:** `/grill-with-docs`. É uma skill só para o usuário (`disable-model-invocation: true`).

**Arquivos:** `SKILL.md` (original em inglês), `TRADUCAO.pt-BR.md` (tradução) e este `RESUMO.md`.
