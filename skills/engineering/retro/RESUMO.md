# Resumo: retro

**O que faz:** conduz uma retrospectiva de uma sessão de código e propõe melhorias no **ambiente** do agente, para que as próximas execuções sejam melhores. Analisa as sessões (ou a atual, por padrão) em sete categorias: navegação, checagens automatizadas, padrões de código, AGENTS.md global, economia de ferramentas, operações sem efeito e acesso à informação. Ao final, apresenta os candidatos ao usuário em ordem de gravidade.

**Quando usar:** depois de uma sessão em que o agente demorou demais para achar algo, errou algo que uma checagem poderia pegar ou gastou ferramentas caras à toa.

**Como invocar:** `/retro`. É uma skill só para o usuário (`disable-model-invocation: true`).

**Arquivos:** `SKILL.md` (original em inglês), `TRADUCAO.pt-BR.md` (tradução) e este `RESUMO.md`.
