# Rótulos de triagem

As skills falam em termos de seis papéis canônicos de triagem. Este arquivo mapeia esses papéis para as strings reais de rótulo usadas no issue tracker deste repositório.

| Rótulo neste repositório de skills | Rótulo no nosso tracker | Significado |
| ---------------------------------- | ----------------------- | ----------- |
| `needs-triage`                     | `needs-triage`          | O mantenedor precisa avaliar esta issue |
| `needs-info`                       | `needs-info`            | Aguardando o autor fornecer mais informações |
| `ready-for-agent`                  | `ready-for-agent`       | Totalmente especificada, pronta para um agente AFK |
| `ready-for-human`                  | `ready-for-human`       | Precisa de um humano: revisar a tarefa, o código e se a funcionalidade funciona |
| `wontfix`                          | `wontfix`               | Não será tratada |
| `done`                             | `done`                  | Trabalho concluído e aceito; definido pelo `archive-feature` |

Quando uma skill mencionar um papel (por exemplo, "aplique o rótulo de triagem pronto para AFK"), use a string de rótulo correspondente desta tabela.

Edite a coluna "Rótulo no nosso tracker" para que corresponda ao vocabulário que você de fato usa.
